# Envman visual assets

The Envman identity uses a bracketed equals mark, mineral teal, deep ink, and a high-visibility signal color. Assets are authored as SVG so the README and GitHub Pages site stay crisp at any size.

## Files

- `brand-mark.svg` and `favicon.svg` provide the compact symbol.
- `logo-light.svg` and `logo-dark.svg` are color-scheme variants for the repository README and other wide placements.
- `terminal-preview.svg` is a synthetic product view. It contains sample names and values only.
- `social-preview.svg` is the editable 1280 by 640 source for `social-preview.png`, which is used by page metadata and GitHub repository settings.

## Regenerating the social image

Render `social-preview.svg` at exactly 1280 by 640 pixels, then preserve the copyright, source URL, and private-asset notice in the PNG text metadata. Do not use a screenshot containing real environment values.
